The orbital node already held command, navigation, mapping, landing-control, and return responsibility. Blocks `wb-s-20260816-w3a8m`, `wb-s-20260816-x4b9n`, and `wb-s-20260816-y5c1p` define the attitude-control burden created by those roles: reference-frame and mode management, changing mass properties, habitat rotation, flexible truss and tank response, distributed actuation, plume constraints, post-docking model changes, and an independent safe-control path for Mars-delay operations. Sensor and actuator hardware, propellant, computer architecture, accuracies, reserves, and detailed control laws remain open.
