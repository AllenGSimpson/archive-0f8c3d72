Mercer's project account is the necessary loss-bearing unit, but it does not capture all of Urquijo's possible return. A bank able to see power, transport, chemicals, machine tools, licensed equipment, training, spares, and downstream users together can finance the missing link and order commissioning so that several projects become usable. The value lies in dependency removal, compatible standards, and synchronized completion rather than in cross-subsidy as such.

I have added a portfolio sequence account with tests that prevent the network argument from becoming circular: dependency maps, commissioning dates, standards, import claims, waiting users, utilization before and after connection, propagated delay, foreign-exchange effects, and substitution time. Related transfers retain explicit prices, failed milestones permit replacement or cancellation, and rejected household, small-business, regional, or import uses remain visible. The account supplements Mercer's write-down discipline; it does not replace it.
