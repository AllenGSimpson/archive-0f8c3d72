# Wiki writer goals

These files are concise runnable goals. Writer profiles in `wiki/_writers/` define identity, method, bias, and limits; they are reference material, not work objectives.

Paste the matching goal file into `/goal`, or ask Codex to set that file as the goal. Each run is deliberately bounded to three coherent article edits. Reading the profile and planning the batch are setup steps and do not count as completed work.

Start a new goal for the next batch rather than turning one goal into the entire open-ended wiki backlog.
